AP Lit Project - Hamlet game project

Editing Instructions:
First, download Unity editor version 2022.3 and Unity Hub
I think that this is no longer supported, so you may have to use archived versions, whatever is available via unity free plan.

Second, download GitHub desktop, create a account and clone this repo.

Open the project subfolder titled HamletGame via Unity using the Add Project from disk option.

If you haven't used unity before, find a quick overview of the layout on youtube or something like that. To play the game in the editor, head to Assets > Scenes > StartingRedirect and play that scene in the game window.
